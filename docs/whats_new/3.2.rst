****************************
What's New in Photutils 3.2?
****************************

Here we highlight some of the new functionality of the 3.2 release.
In addition to these changes, Photutils 3.2 includes several
smaller improvements and bug fixes, which are described in the full
:ref:`changelog`.

.. contents::
   :local:
   :depth: 2


Dependency Version Updates
==========================


Sky Position Errors from a WCS
==============================

The new :func:`~photutils.utils.pixel_to_sky_errors` function converts
pixel position errors, such as those from centroiding or PSF fitting,
to East and North sky position errors in arcsec. The pixel error
covariance is transported to the sky with the local WCS Jacobian at
each position, so the errors follow the distortion across the field
and are well defined at the celestial poles and across the RA
wraparound. The optional ``xy_cov`` keyword includes the covariance
of the ``x`` and ``y`` errors. The function accepts any WCS that
supports the astropy shared WCS interface, including ``gwcs`` objects::

    >>> from photutils.datasets import make_wcs
    >>> from photutils.utils import pixel_to_sky_errors
    >>> wcs = make_wcs((100, 100))  # 0.1 arcsec pixels
    >>> east_err, north_err = pixel_to_sky_errors(
    ...     wcs, [10.0, 50.0], [20.0, 50.0], [0.1, 0.2], [0.1, 0.2])
    >>> east_err
    <Quantity [0.01, 0.02] arcsec>


Sky Positions in PSF Photometry Results
=======================================

The results tables of `~photutils.psf.PSFPhotometry` and
`~photutils.psf.IterativePSFPhotometry` now include an ``xy_cov``
column with the covariance of the fitted x and y positions. The
covariance is nonzero for an elliptical PSF that is rotated with
respect to the pixel axes. The ``x_err`` and ``y_err`` columns alone
do not describe the position uncertainty in that case.

Both classes also accept a new ``wcs`` keyword in their ``__call__``
method. If a WCS is input, the results table includes the sky position
of each fitted source (``sky_centroid``) and its errors along the Right
Ascension and Declination directions in arcsec (``sky_centroid_ra_err``
and ``sky_centroid_dec_err``). The sky errors are computed with
`~photutils.utils.pixel_to_sky_errors` and include the ``xy_cov``
covariance. For an `~astropy.nddata.NDData` input, the WCS is taken
from its ``wcs`` attribute, so these columns are added whenever the
input has a WCS::

    >>> from photutils.datasets import make_wcs
    >>> wcs = make_wcs(data.shape)
    >>> psfphot = PSFPhotometry(psf_model, fit_shape, finder=finder,
    ...                         aperture_radius=4)
    >>> phot = psfphot(data, error=error, wcs=wcs)
    >>> phot.colnames[-4:]
    ['xy_cov', 'sky_centroid', 'sky_centroid_ra_err', 'sky_centroid_dec_err']

New Deprecations
----------------

ASDF Subpackage
^^^^^^^^^^^^^^^

The ASDF converters, extension, schemas, and manifests have moved to the
new ``photutils.asdf`` subpackage. Importing from the old locations
(``photutils.converters`` and ``photutils.extension``) is deprecated and
will be removed in version 4.0. Update your imports::

    # Old (deprecated)
    from photutils.converters import CircularApertureConverter

    # New
    from photutils.asdf.converters import CircularApertureConverter

Most users never import these modules directly, because ``asdf`` loads
the photutils extension automatically. The ASDF tags and schema URIs are
unchanged, so existing ASDF files remain readable.
