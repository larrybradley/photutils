****************************
What's New in Photutils 3.2?
****************************

Here we highlight some of the new functionality of the 3.2 release.
In addition to these changes, Photutils 3.2 includes several
smaller improvements and bug fixes, which are described in the full
:ref:`changelog`.

.. contents::
   :local:
   :depth: 2


Source Masks from the Moran's I Statistic
=========================================

The new `~photutils.background.make_morans_i_mask`
function makes a source mask from the `Moran's I
<https://en.wikipedia.org/wiki/Moran%27s_I>`_ spatial autocorrelation
statistic, which measures how strongly each pixel is correlated
with its neighbors within a small patch of the image. Background
noise gives a low value, while sources, including their faint
outer regions, give a high value. The statistic does not depend
on the background level or on the amplitude of the noise, so the
mask can be made before the background is known and then input to
`~photutils.background.Background2D`::

    >>> from photutils.background import Background2D, make_morans_i_mask
    >>> from photutils.simulation import make_100gaussians_image
    >>> data = make_100gaussians_image()
    >>> mask = make_morans_i_mask(data)
    >>> bkg = Background2D(data, (50, 50), mask=mask, filter_size=(3, 3),
    ...                    exclude_percentile=50.0)

The threshold is set relative to the typical value of the statistic
in the image, so it adapts to images with correlated noise such as
resampled mosaics. The map of the statistic itself is available from the
new `~photutils.background.make_morans_i_map` function.

See :ref:`morans_i_mask` for more details.


Isophote Fitting Improvements
=============================

The elliptical isophote fits of `~photutils.isophote.Ellipse` are now
about 5 times faster, and about 70 times faster for masked images.
Nonfinite (NaN or infinity) image values are now excluded from the
fits, like masked pixels.

Several differences from the STSDAS ``ellipse`` task that
`photutils.isophote` is based on were also fixed. They include the
convergence criterion, the ``maxgerr`` stopping criterion, the radius
where the local intensity gradient is measured, and the starting
geometry of the inward fits. Because of these fixes, the fitted
isophotes differ slightly from those of previous versions. The fits
of noisy images typically need a few more iterations and extend to
larger semimajor axis lengths. See the :ref:`changelog` for the
complete list of fixes.


New photutils.simulation Subpackage
===================================

A new :ref:`photutils.simulation <simulation>` subpackage provides
tools for making simulated images. It starts with versions of the
``photutils.datasets`` tools and of
``photutils.psf.make_psf_model_image`` whose optional arguments are
keyword-only.

Scene Generators
----------------

:func:`~photutils.simulation.make_model_params` has two new keywords.
``log_params`` samples the named parameters uniformly in log10, which
flux and size distributions in a completeness test need, and ``kind``
adds a column that labels the population, so tables of stars and
galaxies can be stacked and scored together.

Two new functions make controlled scenes for the hard cases of source
detection. :func:`~photutils.simulation.make_pair_params` makes close
pairs at set separations and flux ratios, and
:func:`~photutils.simulation.make_satellite_params` places sources
around host sources, such as faint stars on bright galaxies::

    >>> from photutils.simulation import (make_model_params,
    ...                                   make_pair_params,
    ...                                   make_satellite_params)
    >>> stars = make_model_params((512, 512), 100, flux=(3, 300),
    ...                           log_params=('flux',), kind='star')
    >>> pairs = make_pair_params((512, 512), 20, (2, 6), flux=(50, 200),
    ...                          flux_ratio=(0.1, 1), kind='pair')
    >>> hosts = make_model_params((512, 512), 5, r_eff=(10, 20),
    ...                           min_separation=100, border_size=60)
    >>> on_hosts = make_satellite_params(hosts, 10, (0.5, 2.5),
    ...                                  radius_unit='r_eff',
    ...                                  flux=(5, 300), kind='star_on_gal')

New Deprecations
----------------

ASDF Subpackage
^^^^^^^^^^^^^^^

The ASDF converters, extension, schemas, and manifests have moved to the
new ``photutils.asdf`` subpackage. Importing from the old locations
(``photutils.converters`` and ``photutils.extension``) is deprecated and
will be removed in version 4.0. Update your imports::

    # Old (deprecated)
    from photutils.converters import CircularApertureConverter

    # New
    from photutils.asdf.converters import CircularApertureConverter

Most users never import these modules directly, because ``asdf`` loads
the photutils extension automatically. The ASDF tags and schema URIs are
unchanged, so existing ASDF files remain readable.

Isophote Fitting Keywords
^^^^^^^^^^^^^^^^^^^^^^^^^

The ``maxgerr`` and ``going_inwards`` keywords of
`~photutils.isophote.EllipseFitter.fit` and
`~photutils.isophote.Ellipse.fit_isophote` are deprecated and will be
removed in version 4.0. They have no effect. The ``maxgerr`` criterion
compares consecutive isophotes, so it is applied only by
`~photutils.isophote.Ellipse.fit_image`.

The ``threshold`` keyword and the ``set_threshold`` method of
`~photutils.isophote.Ellipse` are also deprecated and will be removed
in version 4.0. They have no effect because
`~photutils.isophote.Ellipse` does not run the object centerer. Use
`~photutils.isophote.EllipseGeometry.find_center` to refine the initial
center before fitting.


Datasets Subpackage
^^^^^^^^^^^^^^^^^^^

The ``photutils.datasets`` subpackage is deprecated and will be removed
in version 4.0. For the functions that make simulated data, use the
functions of the same name in :ref:`photutils.simulation <simulation>`
instead. Their optional arguments are keyword-only, so any optional
argument must be passed by name. The ``load_*`` functions and
``get_path`` have no replacement and keep their existing deprecation.
Update your code::

    # Old (deprecated)
    from photutils.datasets import make_noise_image
    noise = make_noise_image((100, 100), mean=5, stddev=2, seed=123)

    # New
    from photutils.simulation import make_noise_image
    noise = make_noise_image((100, 100), mean=5, stddev=2, seed=123)

The ``n_nodes`` keyword of
:func:`~photutils.simulation.make_model_image` replaces the
``discretize_method`` and ``discretize_oversample`` keywords of the
deprecated ``photutils.datasets.make_model_image``.

``make_psf_model_image``
^^^^^^^^^^^^^^^^^^^^^^^^

The ``photutils.psf.make_psf_model_image`` function is deprecated and
will be removed in version 4.0. Use
:func:`~photutils.simulation.make_psf_model_image` instead::

    # Old (deprecated)
    from photutils.psf import make_psf_model_image
    data, params = make_psf_model_image((100, 100), psf_model, 10,
                                        min_separation=5, seed=123)

    # New
    from photutils.simulation import make_psf_model_image
    data, params = make_psf_model_image((100, 100), psf_model, 10,
                                        min_separation=5, seed=123)
