Spurious Detections in the Wings of Bright Sources
==================================================

A new :func:`~photutils.segmentation.get_spurious_labels` function
implements the SourceExtractor CLEAN test. Bright sources can produce
spurious detections in their wings, such as fragments of a stellar
halo or a diffraction spike that rise above the detection threshold
as separate segments or deblended children. Each source is described
by a Moffat-like wing model built from its isophotal measurements, and
a fainter source is judged spurious when the wing model of a brighter
neighbor, evaluated at its centroid, exceeds the height of its
``n_pixels``-th brightest pixel above the threshold. The
``clean_param`` keyword sets the wing model exponent (the
SourceExtractor ``CLEAN_PARAM`` parameter). The Moffat wing is a
prior tuned for stars that overestimates the wings of galaxies,
especially exponential disks. The ``wing_model='measured'`` option
instead measures the brighter source's own light in an elliptical
annulus at the fainter source's distance, so it follows whatever
profile the source has.

The function returns a table of the spurious labels and the label of
the surviving source that absorbs each one, and it does not modify the
segmentation image. Merge each spurious segment into its absorber with
:meth:`~photutils.segmentation.SegmentationImage.reassign_labels` to
match SourceExtractor, or drop the spurious segments with
:meth:`~photutils.segmentation.SegmentationImage.remove_labels` to
match the SEP package. :class:`~photutils.segmentation.SourceFinder`
has new ``clean``, ``clean_param``, and ``wing_model`` keywords that
run the test after deblending and merge the spurious segments into
their absorbers.

New Deprecations

ASDF Subpackage
^^^^^^^^^^^^^^^

The ASDF converters, extension, schemas, and manifests have moved to the
new ``photutils.asdf`` subpackage. Importing from the old locations
(``photutils.converters`` and ``photutils.extension``) is deprecated and
will be removed in version 4.0. Update your imports::

    # Old (deprecated)
    from photutils.converters import CircularApertureConverter

    # New
    from photutils.asdf.converters import CircularApertureConverter

Most users never import these modules directly, because ``asdf`` loads
the photutils extension automatically. The ASDF tags and schema URIs are
unchanged, so existing ASDF files remain readable.
