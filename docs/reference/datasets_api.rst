================================================
Datasets (:mod:`photutils.datasets`, deprecated)
================================================

The ``photutils.datasets`` subpackage is deprecated and will be removed
in version 4.0. For the functions that make simulated data, use
:mod:`photutils.simulation` instead. The ``load_*`` functions and
``get_path`` have no replacement and keep their existing deprecation.
